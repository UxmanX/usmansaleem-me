# Portrait provenance

The only image source is supplied existing `../../assets/headshot.jpg` (1568×2281), visually inspected before implementation. Source crop Canvas `(260,590,1050,1450)` means x/y/width/height. Original file unchanged. No generated person, geometric photographic cutout or stock replacement.

The source luminance is sampled into 89×116 heights and cap tones; normals come from neighboring heights. This is a photographic mechanical interpretation, not depth captured from Usman's face. Metallic cap sprites are authored procedural canvas gradients, not photographic assets. No shipping derived raster was added; evidence is outside the public repo in `homepage-research/portrait-qa/`.
